# docs 폴더 사용 지침

이 프로젝트의 모든 문서(리서치, 기획, 개발 노트, 디자인 자료 등)는 프로젝트 루트가 아니라 **이 `docs/` 폴더 안**에 저장합니다.

## 하위 폴더 구조

| 폴더 | 용도 |
|---|---|
| `docs/기획/` | 아이디어 리서치, 기획서, 사회문제 분석 등 기획 관련 문서 |
| `docs/개발/` | 기술 스펙, 개발 노트, 아키텍처 문서 등 개발 관련 문서 |
| `docs/디자인/` | 디자인 컨셉, UI/UX 자료, 아트 레퍼런스 등 디자인 관련 문서 |

## 규칙

- 새 문서를 만들 때는 반드시 위 세 폴더 중 성격에 맞는 곳에 넣을 것 (루트나 `docs/` 바로 아래에 파일을 두지 않음)
- 어느 폴더에도 애매하게 걸치는 문서는 문서의 주된 목적(리서치/의사결정 → 기획, 구현 → 개발, 비주얼 → 디자인)을 기준으로 분류
- 다른 대화나 세션에서 "docs 안 참고해줘"라고 하면, 이 파일을 먼저 읽고 폴더 구조를 파악한 뒤 관련 하위 폴더의 문서를 찾아 참고할 것
